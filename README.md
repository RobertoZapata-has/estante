# Estante

Biblioteca de ebooks (EPUB) para el celular y la tablet, con modo tinta electrónica,
pantalla siempre encendida y lectura en voz alta.

## Publicar en GitHub Pages
1. Crear un repositorio nuevo llamado `estante`.
2. Subir TODOS estos archivos respetando las carpetas (`fonts/` e `icons/`).
3. Settings › Pages › Branch: `main` / carpeta `/ (root)` › Save.
4. Abrir https://robertozapata-has.github.io/estante/ en Chrome del celular › menú ⋮ › "Agregar a la pantalla principal" (Instalar app).

Instalada, aparece en el menú "Compartir" de Android: desde el administrador de archivos
o Drive podés compartir un .epub directo a Estante.

Para publicar una versión nueva: subir los archivos cambiados y, si cambia algo
del funcionamiento sin internet, subir el número de `estante-v1` en `sw.js`.
